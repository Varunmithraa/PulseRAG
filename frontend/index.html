✨ What Makes PulseRAG Different?
🌐
Live Streaming Web Intelligence

Unlike standard LLMs limited by knowledge cutoff dates, PulseRAG ingests live RSS streams (BBC, TechCrunch, CoinDesk) into a sliding temporal buffer with exponential recency-decay scoring.

🧠
Self-Correcting Reasoning (CRAG)

An autonomous LangGraph state machine routes intent, retrieves candidates, grades factual relevance, and prunes hallucinated noise before generating answers with verified citations.

💾
Dual-Tier Cognitive Memory

Combines multi-turn episodic conversation checkpoints with semantic long-term memory in SQLite + ChromaDB, remembering your watchlist and preferences across sessions.
